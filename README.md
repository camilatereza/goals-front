# Goals

### Projeto para gerenciar metas de acordo com as áreas da vida

--

## Como executar:
<p>
-> Para rodar API mockada localmente  <br />
<code> npm run server </code> <br />
-> Para executar o front <br />
<code> ng serve </code>
</p>

## Base:
<p> 
A organização das metas são baseadas em dois métodos juntos <br />
Método SMART: <br />
-> As metas precisam ter as seguintes caracteristicas: <br />
&emsp; Específicas
&emsp; Mensuráveis
&emsp; Atingíveis
&emsp; Relevantes
&emsp; Temporais
<br />
Método Areas da vida: <br />
-> As metas precisam focar em áreas especificas da vida, como: pessoais, profissionais... 
</p>
